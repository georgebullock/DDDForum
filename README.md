# DDDForum via The Software Essentialist Course

## What Is This

A repo for completing Khalil Stemmler’s _Software Essentialist_ course project, DDD Forum.

## Purpose

The purpose is to strengthen my ability to design scalable, testable software via hands-on practice applying problem decomposition, clean architecture, and systematic simplicity.

Another objective is learning how to use the **FA²STR framework** (_Find → Architect → Automate → Specify → Test → Refine_) effectively in real projects.

## What You’ll Find

A small project that starts off using a basic MVC architecture and progresses to a more advanced hexagonal architecture.

`In Progress`: Kicking off course in mid October 2025.
